# 内置排版风格预设

## 深色模式（夜间模式）适配规范

微信夜间模式不是“换肤”，而是对文章里**每一个显式设置的颜色**跑一遍反色算法（`wechatjs/mp-darkmode`）：

| 颜色情况 | 夜间结果 | 说明 |
|---------|---------|------|
| 白 / 近白背景（灰阶 L>40% 或感知亮度>250） | 亮度取反到 `#191919` 附近 | 与页面底色接近，本身不算突兀 |
| 浅色淡彩背景（感知亮度 190~250，如 `#f0f6fc`、`rgb(231,244,255)`） | **压成中灰色块** | 这就是“深浅不一马赛克”的来源 |
| 半透明白背景（`rgba(255,255,255,0.x)`） | 说不清的中灰 | 禁用 |
| 高饱和中间调（品牌蓝/橙等） | 保持不变 | 可放心用作边框、色块、强调文字 |
| 深色文字 | 反白/提亮 | 保留深色即可，夜间自动可读 |
| `var(--weui-*)` | 不被算法处理，由客户端解析成原生深色 | 最可靠的“自适应”手段 |

### 预设配色三原则（所有预设已遵守，新增预设必须遵守）

1. **页面底色**：`background-color: var(--weui-BG-1, <白天色>)` — 白天≈原色（`#F7F7F7`），夜间 `#1E1E1E` 原生页面色
2. **卡片 / 引用 / 列表 / 章节框等浅色块**：`background-color: var(--weui-BG-2, <白天色>)` — 白天 `#FFFFFF`，夜间 `#191919` 原生卡片色
3. **代码（行内与代码块）**：`background-color: var(--weui-BG-3, <白天色>)` — 白天 `#F7F7F7`，夜间 `#404040` 原生代码色，夜间仍可见

fallback 写当前白天色：本地预览、非微信环境显示的仍是原来的颜色，白天效果不变；夜间由微信客户端解析变量为原生深色，整篇只有 2~3 个统一灰阶，不再有马赛克。

> 本地验证：渲染时加 `--output-dark-preview <路径>`（`scripts/utils/dark-preview.js`），生成模拟微信 mp-darkmode 算法的夜间预览页，发布前先在浏览器里检查。

## 如何选择

| 你的文章类型 | 推荐预设 | 原因 |
|-------------|---------|------|
| 职场/科技/工具评测 | 蓝点笔记 | 蓝白配色专业理性，适合干货输出 |
| 成长/情感/生活方式 | 蓝紫徽章 | 蓝紫温柔清新，大间距更有呼吸感 |
| 设计/美学/有气质的内容 | 极简雅致 | 灰白极简，双圆点标题，留白充分显高级 |
| 想要活泼撞色 + 卡片式排版 | 活力徽章 | 蓝橙对比强，PART 徽章 + 卡片结构视觉冲击力强 |
| 科技资讯/行业分析/AI 内容 | 极客科技 | 数字编号标题有辨识度，科技媒体风格 |
| AI 工具/科普/方法论 | 公众号蓝黄线框 | 章节独立框结构清晰，蓝黄撞色有辨识度 |
| 需要强视觉冲击力 | （复刻模式） | 找一篇喜欢的公众号文章直接复刻 |

## 新增预设

新增一个预设只需：

1. 在 `scripts/presets/` 下复制一个现有预设文件（如 `blue-dot-notes.js`）
2. 修改 `id`、`name`、`tagline`、`description`、`suitableFor`、`meta`
3. 调整 `STYLES` 对象中的样式值
4. 如果有特殊装饰（标题装饰、引用块样式等），在 `decorations` 中自定义对应 `makeXxx` 函数
5. 在 `scripts/presets/index.js` 中注册
6. **夜间模式适配**（必做）：浅色块一律写 `var(--weui-BG-1/2/3, <白天色>)`，不写半透明白背景；`meta.darkMode` 标注适配方式；渲染时用 `--output-dark-preview` 检查夜间效果

大约 100-200 行代码即可完成一个新预设。
