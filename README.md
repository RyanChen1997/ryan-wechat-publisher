# Ryan WeChat Publisher

**公众号文章排版发布助手** —— 把一篇普通的 Markdown / Word 文章，变成一篇好看的公众号文章：先在一个可视化预览器里确认效果，再一键复制粘贴到公众号编辑器。

## ✨ 它能做什么

### 1. 内置多套排版模板，一键套用

不用懂任何代码，选一套风格就能排：

| 预设 | 风格 |
|------|------|
| 蓝点笔记 | 清爽的蓝色圆点笔记风 |
| 蓝紫徽章 | 徽章式标题 + 蓝紫配色 |
| 极简雅致 | 克制留白，适合深度长文 |
| 活力徽章 | 彩色徽章，活泼吸睛 |
| 极客科技 | 深色代码感，技术文章首选 |
| 公众号蓝黄线框 | 经典公众号框架感 |
| 童趣手绘 | 动态笔刷标题、手绘数字与多色高亮 |

7 套模板分在 6 个分类里（商务 / 简约 / 清新 / 卡通 / 时尚 / 极简；动漫 / 文艺 / 复古 / 中国风暂无模板，加了会自动出现）。想知道长什么样，跑一次模板画廊就能一次看完：

```bash
node scripts/build-gallery.js --open
```

画廊顶部是 3 个推荐位，下面可以**按分类翻阅**（分类标签自带套数），都用同一篇示例文章渲染，点一下就能对比效果。

### 2. 可视化预览器，所见即所得

排完版会自动打开一个本地预览器：可以切**电脑端 / 手机端**、切**白天 / 夜间**（按微信深夜模式算法模拟，提前发现灰块马赛克），侧栏还会盯着图片状态和夜间体检结果。

### 3. 交付前自动校验

每次生成排版都会自动跑三道校验收口：文章内容有没有被改（内容一致性）、样式会不会被微信过滤（微信兼容）、图片文件在不在（图片存在性）。任一道没过就不进预览环节，先把问题修好。

### 4. 一键复制到公众号

预览器右上角点「复制到公众号」，整篇排版（连内联样式）直接进剪贴板，粘进公众号编辑器不会掉样式。

**图片也会跟着过去，而且不需要配置任何服务**：预览器会把本地图片压到 1080px 后内联进复制内容，公众号编辑器在粘贴时会把图抓下来转存到自己的 CDN（图片地址会变成 `mmbiz.qpic.cn`）。不需要图床、不需要本地服务器、也不需要云托管。

预览器顶栏还有一个「复制时传图床」开关，**默认就是开的**：图片在你**点「复制到公众号」那一刻**才上传到 Litterbox（匿名临时托管、免登录免配置），按钮上弹出上传进度条，完成后内联 base64 自动换成 https 链接 —— 复制内容从「几 MB 的 base64」变成「几 KB 的 URL」，大图和动图不用再担心粘贴失败。上传失败的图自动保留内联，不会丢图；不想用第三方托管就取消勾选（或渲染时加 `--no-image-host`），回到纯内联。链接最长 72 小时后失效，压在发布前用即可。

## 📖 怎么使用

**不需要学任何命令。** 直接跟你的 AI 说人话，比如：

**例 1：用内置模板排版并发布**
```text
请帮我把 /Users/me/文章.docx 排版并发布到公众号，用「极简雅致」风格
```

**例 2：用某个模板排版，自己复制粘贴发布**
```text
帮我把这篇文章排版，用「公众号蓝黄线框」风格
排好打开预览给我看，我再自己复制到公众号
```

**例 3：只要排版，先看效果**
```text
把这篇文章排版成公众号格式，先给我预览，我确认再说
```

**例 4：换一套模板重排**
```text
刚才那篇换成「童趣手绘」风格，重新给我预览
```

AI 会引导你一步步确认（解析文章 → 确认结构 → 选模板 → 确认排版方案 → 渲染并校验 → 预览器里复制），全程只需要回答“可以 / 换一套 / 用第三个标题”。
